# Programmer 架构审查台

> 本页及 HTML 保留 `0715627` 重构前快照，不代表当前 Rust 实现；原 localStorage 草案不重置。当前结构见 [新版所有权图](architecture-ownership.html)，验收见 [实施清单](architecture-implementation.md)。

打开 `architecture-review.html` 即可使用，不需要 HTTP 服务或网络。

## 范围

- 源码基线：版本 0.2.22、HEAD `0715627` 加读取时的工作区。
- 覆盖 `main.rs` 声明的 30 个顶级模块，另列 main 组合根，共 31 个条目。
- 嵌入 169 个 Rust 源文件的清单、8 条核心流程、状态与恢复矩阵。正文审查概念/职责/所有权边界；原 16 条实现风险与保留项作为附录，不能代替抽象审查。
- 当前实现、静态风险和重设计提案分开标注。不是逐函数审计；业务风险未做故障注入，候选设计没有实施。
- 行数包括注释、空行与测试，不能当作复杂度评分。

## 使用

- 系统地图以实际类型为节点，切换工具接口与五个实现、执行端口与策略、运行对象与快照。节点区分 trait / struct / enum / DTO，列出关键成员和方法；有向连线区分持有、共享、借用、实现与转换。点击显示该视角下的源码依据和抽象问题。字段为节选，三图不是全量类型索引。
- 点击节点高亮直接上下游，其他关系淡化；「显示全部关系」恢复全图；支持全屏图，以及「适应宽度 / 原始字号」切换。键盘 Tab 聚焦节点，Enter/空格选择。窄屏在图内横向滚动，避免把文字缩到不可读。
- 搜索同时过滤模块目录与附录风险清单（不筛选静态概念审查正文）。`/` 聚焦搜索，搜索框内 `Esc` 清空。
- 附录风险项支持优先级筛选、展开收起、填写结论与笔记；保留旧笔记存储键。
- 笔记保存在浏览器 localStorage，文件位置/浏览器改变可能不共享。用「导出审查笔记」保存 JSON。当前没有导入功能。
- 源码链接相对仓库定位；浏览器未必支持 Rust 文本的行号锚点。
- 打印会展开审查项；流程与地图只打印当前选中的视图，不是完整八流程打印报告。
